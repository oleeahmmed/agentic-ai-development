# notes — দৈনিক শেখা

প্রতিটি সেশনের শেষে ৫ মিনিটের নোট। ফাইল নাম: `YYYY-MM-DD.md`।

## টেমপ্লেট

```markdown
# 2026-11-14

## আজ যা করলাম
-

## নতুন যা বুঝলাম
-

## কোথায় আটকালাম
- সমস্যা:
- চেষ্টা:
- সমাধান / পরের ধাপ:

## আগামীকাল
-
```

## কেন

- ভুলের প্যাটার্ন ধরা পড়ে
- "মনে হয় শিখেছি" বনাম সত্যিই শেখা — পার্থক্য বোঝা যায়
- কোডের বাইরের সিদ্ধান্ত (কেন এভাবে করলাম) সংরক্ষণ হয়
