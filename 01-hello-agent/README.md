# 01 — Hello Agent

> অবস্থা: **অপেক্ষায় (Phase 2)।** ফেজ শুরু হলে এই ফাইলে ধাপে ধাপে হাতে-কলমে গাইড, কোডের ব্যাখ্যা ও পরীক্ষার ফলাফল যোগ হবে।

## লক্ষ্য

একজন "নতুন কর্মী" বানানো — যে Little Office Ltd.-এর সহায়ক, কথোপকথন মনে রাখে, কিন্তু এখনো কোনো টুল ব্যবহার করে না।

## যা শিখবেন

- LLM কীভাবে উত্তর বানায়, token ও context window
- system / user / assistant message
- system prompt-এর গঠন: পরিচয়, নিয়ম, টোন, আউটপুট
- streaming, token খরচ
- hallucination কী এবং কেন হয়

## যা বানাবেন

- CLI চ্যাট: `agent.py`
- পার্সোনা ও কোম্পানি হ্যান্ডবুক: `prompts/system.md`
- পুরো কথোপকথন `messages` লিস্টে রাখা, `/reset` কমান্ড
- প্রতি উত্তরের পরে token হিসাব

## শেষ করার মানদণ্ড

- ১০ টার্নের কথোপকথনে পার্সোনা ঠিক থাকে
- হ্যান্ডবুকে নেই এমন তথ্য বানিয়ে বলে না
- `/reset` কাজ করে
- execution token count দেখায়

## শর্ত

Phase 0 সম্পন্ন (API key কাজ করছে) + Phase 1 (Python বেসিক)।

## নোট

এটি এখনো chatbot — এজেন্ট হবে Phase 3-এ, যখন LLM নিজে সিদ্ধান্ত নেবে কোন টুল চালাবে।
