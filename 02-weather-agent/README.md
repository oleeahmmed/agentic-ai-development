# 02 — Weather Agent

> অবস্থা: **অপেক্ষায় (Phase 3)।** ফেজ শুরু হলে এই ফাইলে সম্পূর্ণ গাইড ও কোড ব্যাখ্যা যোগ হবে।

## লক্ষ্য

LLM-এর হাতে "হাত" দেওয়া — যেন সে নিজে আবহাওয়ার টুল ব্যবহার করে সত্য তথ্য এনে উত্তর দেয়।

## যা শিখবেন

- Function calling-এর ভেতরের প্রবাহ
- JSON schema দিয়ে টুল বর্ণনা
- **ফ্রেমওয়ার্ক ছাড়া নিজের agent loop লেখা**
- টুলের আর্গুমেন্ট validate করা ও errored result ফেরত দেওয়া
- একাধিক টুলের মধ্যে সঠিকটি বেছে নেওয়া
- infinite loop ঠেকানো (max steps)

## যা বানাবেন

- `agent_loop.py` — নিজের লেখা while loop
- `tools.py` — Open-Meteo API (ফ্রি, key নেই)
  - `get_current_weather(city)`
  - `get_forecast(city, days)`
  - `convert_temperature(value, unit)`
- প্রতিটি টুল কলে লগ

## শেষ করার মানদণ্ড

- "আগামীকাল চট্টগ্রামে বৃষ্টি হবে?" → সঠিক টুল ও আর্গুমেন্ট
- অজানা শহরে ভদ্রভাবে ব্যর্থ, বানিয়ে উত্তর নয়
- সর্বোচ্চ ৫ ধাপে থামে
- loop-এর প্রতিটি লাইন নিজে ব্যাখ্যা করতে পারেন
