# shared — কমন কোড

> অবস্থা: **অপেক্ষায়।** একই কোড দুইবার লিখতে হলে এখানে তুলে আনবেন।

## ভবিষ্যতে যা থাকবে

- `llm.py` — এক জায়গায় client তৈরি, model config, retry
- `skill_loader.py` — `SKILL.md` পড়া ও frontmatter আলাদা করা (বর্তমানে `ai-mini-office/skill_loader.py`-তে আছে)
- `logging.py` — প্রতিটি LLM ও tool call-এর structured log
- `env.py` — `.env` লোড ও যাচাই

## নিয়ম

- এখানে রাখবেন শুধু সত্যিই পুনর্ব্যবহারযোগ্য জিনিস।
- প্রজেক্ট-নির্দিষ্ট যুক্তি নিজের ফোল্ডারেই থাকবে।
- কিছু সরানোর আগে দুটি প্রজেক্টে সত্যিই একই কোড আছে কি না দেখুন — আগেভাগে abstraction বানাবেন না।
