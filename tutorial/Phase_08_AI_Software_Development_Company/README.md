# Phase 08 — AI Software Development Company

এই Phase-এ Phase 01–07-এর জ্ঞান একত্র করে একটি human-supervised AI Software Development Company তৈরি করবে।

## Chapters
- `CHAPTER_39_COMPANY_ARCHITECTURE.md` — product scope, requirements, architecture, data model, workflow ও safety boundary
- `CHAPTER_40_END_TO_END_CAPSTONE.md` — runnable Python MVP, specialist agents, SQLite task board, LangGraph pattern, tests ও production roadmap

## Learning outcomes
1. Supervisor ও specialist agent-এর দায়িত্ব আলাদা করা।
2. Skills, tools, memory, state ও orchestration একত্র করা।
3. Requirements থেকে task, code proposal, test ও security review workflow তৈরি করা।
4. Human approval ও audit trail design করা।
5. MVP থেকে production SaaS-এ যাওয়ার roadmap তৈরি করা।

## Prerequisites
Python basics, virtual environment, OpenAI API basics এবং Phase 02–07-এর Skills, Memory, Tool Calling, Agent Loop, Production Engineering ও LangGraph।

## Safety
এটি educational MVP। Human approval ছাড়া production deployment, destructive action বা arbitrary shell execution করবে না। LLM output trusted code নয়। Production-এ authentication, tenant isolation, sandboxing, audit logs, secrets management, quotas, monitoring ও backups যোগ করতে হবে।

## Study plan
প্রতিদিন ৪ ঘণ্টা: ১ ঘণ্টা concept, ১ ঘণ্টা code, ১ ঘণ্টা run/debug, ১ ঘণ্টা homework।
